# Eden Farm Qatar — online store

Storefront in English and Arabic, order system with delivery-area check, order tracking, repeat orders,
and a private admin panel. Customers pay the rider on delivery (cash, card or bank transfer).

The homepage leads with our speciality, **Oryx Mushrooms** (white button, brown, portabella) grown at Eden Farm,
followed by vegetables, fresh herbs, Sidr honey and bundles.

## Run it on your computer

Needs [Node.js 20+](https://nodejs.org).

```bash
npm install
npm start                 # http://localhost:3000   Arabic: /ar/   admin: /admin
```

With no `DATABASE_URL`, the shop uses a built-in Postgres database stored in `./data` (nothing to install).
On first start it is filled with the catalogue in `server/seed/` (English + Arabic).

Create or reset a staff account (you will be asked for the password):

```bash
npm run create-admin -- owner@edenfarm.qa
```

## What customers get

- **Delivery check**: on the first visit the shop offers a one-tap location check (automatic if the browser already
  allows location). Customers can also search a place or move a map pin, so they can order for any address.
  The shop says straight away whether we deliver there; checkout needs a pin inside a delivery area.
- **Favourites**: tap ♡ on a product; the heart in the header (or "Saved" on phones) shows them with add buttons.
- **Repeat orders**: at checkout, choose "Just once", every week, every 2 weeks, every month, or any 3–90 days.
- **Order tracking**: after ordering, "Track your order" shows Received → Confirmed → Out for delivery → Delivered,
  plus the rider's name, phone and live-location link once it's on the way. Customers can also find an order at
  `/track.html` with the order number + mobile number. The page refreshes itself every 30 seconds.
- **Arabic**: every page has an Arabic version at `/ar/...` (right-to-left, Arabic fonts), switched with
  "العربية" / "English". Basket and favourites carry over between languages.

## Admin panel (`/admin`)

Not linked anywhere on the site; without signing in, people only ever see the sign-in page.

- **Orders**: new orders appear automatically, with a sound. Repeat customers are marked **★ Regular** and listed
  first. Call or WhatsApp the customer, open the exact delivery pin in Google Maps, add the rider's name, phone and
  (optional) live-location link, and move the order along: New → Confirmed → Out for delivery → Delivered.
- **Repeat orders**: every regular customer with their interval and next delivery date; due ones are highlighted.
  "Create next order" makes a new order with the same basket at today's prices. Pause, resume, stop, or change
  the interval or next date.
- **Products** and **Bundles**: add, edit, hide, delete, photos, pack sizes and prices, discounts with an end date,
  and the Arabic text for each (pack sizes like "500 g" are translated automatically if left empty).
- **Settings**: pause orders, delivery fee, free-delivery amount, minimum order, **delivery areas on a map**,
  same-day cutoff, delivery slots and hours, "Popular right now" search suggestions (English + Arabic),
  WhatsApp number, checkout area suggestions, your password.

Changes show in the shop immediately.

## Location, maps and tracking: how they work

- Location uses the phone's GPS through the browser, only after the customer allows it. It only works on HTTPS
  (and on `localhost`), so the live site must use HTTPS.
- Maps and address search use OpenStreetMap (free, no key). Address lookups go through our server, cached and
  limited to 1 per second as OpenStreetMap requires. If the shop gets busy, switch to a paid map provider
  (`GEOCODER_URL`, tile URL in `js/app.js` and `admin/app.js`).
- Rider tracking: staff paste the rider's live-location link (e.g. WhatsApp or Google Maps "share live location")
  into the order. Fully automatic GPS tracking would need a rider app; see "Next features".

## Editing text, and the Arabic translation

- Page text is in the HTML files; the four help pages are generated by `python scripts/make-help-pages.py`.
- Arabic text lives in `i18n/ar.json` (`pages` for page text, `ui` for messages from the scripts). The Arabic pages
  are built from the English ones on the server, so layout changes only happen once.
- After changing English text, run `npm run i18n`: it lists every sentence that still needs Arabic.
  Add them to `i18n/ar.json`. Until then, that sentence shows in English on the Arabic page.

## How orders stay correct with many customers at once

- The browser only sends *what* was ordered. The server prices everything, applies discounts and the delivery fee,
  checks the pin is inside a delivery area, and rejects the order if the total the customer saw is out of date.
- Every checkout carries a unique key, so a double tap or a retry on a bad connection never creates two orders.
- Each order is written in one database transaction and gets its own number (EF-1001, EF-1002, …).
- Same-day cutoff and delivery slots are checked on the server in Qatar time.
- Spam protection: a hidden form field, plus a limit of orders per visitor per 10 minutes.
- Stock is treated as unlimited. To stop selling something, hide it (or pause all orders in Settings).

## Going live

1. **Database**: create a Postgres database on [Supabase](https://supabase.com) or [Neon](https://neon.tech)
   and copy the connection string (Supabase: *Project Settings → Database → Connection pooling*, port 6543).
2. **Hosting**: any Node.js host, e.g. [Render](https://render.com) or [Railway](https://railway.app).
   Build command `npm install`, start command `npm start`.
3. **Environment variables** (see `.env.example`):
   `DATABASE_URL`, `SESSION_SECRET` (48 random characters), `NODE_ENV=production`, `TRUST_PROXY=1`,
   and for the first start only `ADMIN_EMAIL` + `ADMIN_PASSWORD` (remove them afterwards).
4. Point `edenfarm.qa` at the host and turn on HTTPS (required for the location button).
5. Health check URL: `/healthz`.
